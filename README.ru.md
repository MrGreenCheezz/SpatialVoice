# 🎧 SpatialVoice

**Объёмный 3D-звук для голосовых каналов Discord.**

Расставьте собеседников в виртуальной комнате и слышите каждый голос оттуда, где стоит человек:
слева или справа, спереди или сзади, близко или далеко.

SpatialVoice — плагин для [Vencord](https://vencord.dev), который превращает обычный голосовой звонок
в общее виртуальное пространство. Ему не нужны виртуальные кабели, перенаправление звука или сторонние
программы: он использует движок Steam Audio, который уже встроен в голосовой модуль Discord. Звук
обрабатывается нативно, без дополнительной задержки.

Если плагин стоит у нескольких участников одного голосового канала, комната у них общая: каждый двигает
свой аватар, а расстановка синхронизируется у всех.

## ✨ Возможности

- **Настоящий 3D-звук (HRTF).** Направление, различие «спереди / сзади», затухание с расстоянием и поглощение
  воздухом. Всё это считает встроенный в Discord движок Steam Audio.
- **Интерактивная карта комнаты.** Аватары перетаскиваются мышью, колесо поворачивает слушателя, говорящие подсвечиваются.
- **Общие комнаты.** Позиции синхронизируются в реальном времени через небольшой сервер, который можно поднять у себя.
  Участников без плагина может расставить любой, и их позиции тоже общие.
- **Без дополнительной задержки.** Звук не покидает движок Discord, плагин передаёт ему только координаты.
- **Бережная синхронизация.** Сервер видит только координаты, ID пользователей и хэш ID канала. Звук через него не идёт.
- **Запасной режим.** Если 3D недоступен, плагин переключается на стереопанораму с громкостью по расстоянию.

## 🧠 Как это работает

Десктопный Discord декодирует и смешивает голос в нативном модуле, поэтому звук не доходит до JavaScript, и
плагин не может обработать его напрямую. Но в этот модуль встроен **Steam Audio**: Discord использует его для
собственной, пока не выпущенной функции пространственного звука. SpatialVoice передаёт движку позицию каждого
участника (`setUserPosition`) относительно того, где стоит и куда смотрит слушатель, а остальное делает движок.

```
┌─ Discord + Vencord ───────────────────┐         ┌─ Сервер (необязательно) ─┐
│ SpatialVoice                          │   WS    │ комнаты по хэшу канала,  │
│  • карта комнаты                      │◄───────►│ рассылает только         │
│  • позиции → нативный Steam Audio     │         │ координаты               │
└───────────────────────────────────────┘         └──────────────────────────┘
```

Заметки о разборе внутренностей Discord — в [NOTES.md](NOTES.md) (на английском).

## 📦 Установка

**Требования:** официальный десктопный Discord, [Git](https://git-scm.com) и [Node.js](https://nodejs.org) 18+.

Vencord не умеет подгружать сторонние плагины во время работы: плагины компилируются внутрь самого Vencord.
Поэтому SpatialVoice устанавливается сборкой Vencord из исходников вместе с плагином. Текущие настройки и
плагины Vencord сохраняются.

Все команды выполняются из одной общей папки.

**1. Склонируйте Vencord и SpatialVoice рядом**

```bash
git clone https://github.com/Vendicated/Vencord
```

```bash
git clone https://github.com/MrGreenCheezz/SpatialVoice
```

**2. Установите зависимости Vencord**

```bash
npm i -g pnpm
```

```bash
pnpm -C Vencord install --frozen-lockfile
```

**3. Добавьте плагин и соберите**

```bash
node SpatialVoice/install-plugin.mjs Vencord
```

```bash
pnpm -C Vencord build
```

**4. Внедрите сборку в Discord.** Это нужно сделать один раз. Сначала полностью закройте Discord, включая иконку в трее.

```bash
pnpm -C Vencord inject
```

**5. Включите плагин.** Запустите Discord и включите **SpatialVoice** в *Настройки → Vencord → Плагины*.


Затем нажмите `Ctrl+R` в Discord. Повторно внедрять сборку не нужно.

Выключите плагин в настройках Vencord. Чтобы вернуться к обычному Vencord, переустановите его
[официальным установщиком](https://vencord.dev/download).
</details>

## 🎮 Использование

1. Зайдите в голосовой канал.
2. Откройте комнату любым способом:
   - ПКМ по каналу → **Пространственная комната**;
   - команда `/spatial` в любом чате;
   - кнопка в Vencord Toolbox.
3. Перетаскивайте аватары, чтобы расставить участников. Колесо мыши над картой поворачивает вас, стрелка показывает направление взгляда.

Под картой отображается текущий режим: **3D-звук (HRTF)** или **стереопанорама** (запасной).

### Настройки

| Настройка | Описание |
|---|---|
| Сервер синхронизации | Адрес сервера (`ws://…` или `wss://…`). Пусто — комната только локальная. |
| Размер комнаты | Размер карты в метрах. |
| Тише с расстоянием | Громкость падает с расстоянием. |
| Расстояние без затухания | В пределах этого расстояния громкость не падает. |
| Поглощение воздухом | Приглушает высокие частоты у дальних голосов. |
| Отражения от стен | Эхо комнаты (эксперимент, нагружает процессор). |
| Простая стереопанорама | Стереопанорама вместо 3D. |

## 🌐 Общие комнаты: свой сервер синхронизации

Сервер — один файл без зависимостей. Он запускается на любой машине с Node.js 18+:

```bash
node server/server.js
```

- По умолчанию слушает порт `8787`, его можно изменить переменными `PORT` и `HOST`.
- Все участники указывают в настройках плагина один и тот же адрес, например `ws://your-host:8787`.
- Для работы через интернет поставьте сервер за reverse proxy с TLS (nginx, Caddy) и используйте `wss://`.
- При первом подключении Vencord попросит разрешить домен сервера. После этого перезапустите Discord.
- Тесты сервера: `npm test` в папке `server/` (нужен Node.js 20.10+).

## 🛠️ Решение проблем

**Под картой «стереопанорама» вместо 3D.** Откройте консоль (`Ctrl+Shift+I`) и выполните:

```js
Vencord.Webpack.findStore("MediaEngineStore").supports("SPATIAL_AUDIO")
```

```js
Vencord.Webpack.findStore("SpatialAudioStore").getSpatialAudioStatus()
```

| Результат | Что значит |
|---|---|
| `supports` возвращает `false` | Голосовой модуль вашей версии Discord не включил 3D. Работает стереорежим. |
| Статус `2` | Устройство вывода работает в моно. Переключите его в стерео. |
| Статус `3` или `4` | Не запустился движок или HRTF. Перезапустите Discord или смените устройство вывода. |

**Нет пункта в меню.** Он появляется только у голосового канала, к которому вы сейчас подключены.

## ❓ Частые вопросы

**Плагин нужен всем участникам?**
Нет. Пространственный звук считается у каждого слушателя отдельно. Участники без плагина слышат звонок как
обычно, и их можно поставить в комнату. Объёмно комнату слышат только те, у кого есть плагин.

**Добавляется ли задержка?**
Нет. Звук обрабатывается движком Discord как обычно, плагин только обновляет позиции.

**Мой голос куда-то отправляется?**
Нет. Через сервер идут только координаты. Если сервер синхронизации не указан, с компьютера ничего не уходит.

**Работает ли в браузере или Vesktop?**
Пока нет. У этих клиентов другой звуковой движок (на WebRTC).

**Это разрешено Discord?**
Клиентские модификации нарушают [условия использования Discord](https://discord.com/terms). Используйте на свой страх и риск.
